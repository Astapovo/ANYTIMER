# AnyTimer v8.01 // Customizable Data Output & Filesystem Sync ⏱️🏭

## Краткий обзор релиза v8.01

Версия **v8.01** развивает мажорную линейку AnyTimer v8.x, добавляя **полнофункциональный инструмент настройки структуры и порядка колонок вывода**, удобный доступ к параметрам столбцов прямо из окна сетевого диска `P:\...`, изумрудное оформление элементов заметок в Конструкторе и нормализацию времени простоя в строгий промышленный формат `ЧЧ:ММ:СС`.

---

## 🚀 Ключевые нововведения в v8.01

### 1. Настройка колонок вывода (CSV / Excel / Сетевой диск)
* Добавлено специализированное модальное окно **«Настройка колонок вывода»**.
* **Прямые точки входа:**
  * Из окна **«Сетевая таблица Excel (диск P:\)»** по кнопке `[ ⚙️ Настроить столбцы таблицы (CSV / Excel) ]`.
  * Из окна **«История и Экспорт»** по кнопке `[ ⚙️ Столбцы ]`.
  * Из главного меню «Настройки AnyTimer».
  * Из окна создания/редактирования заметки.
* **Возможности управления:**
  * Чекбоксы включения/отключения любых полей.
  * Стрелки **▲ / ▼** для изменения порядка следования столбцов в отчетах.
  * Кнопка **«По умолчанию (v8.01)»** для мгновенного сброса на 8 чистых колонок.

### 2. Чистый эталон колонок по умолчанию («Лишние не нужно»)
Стандартный набор столбцов оптимизирован для инженерных журналов и диспетчеризации:
1. **Дата** (`ДД.ММ.ГГГГ`)
2. **Время старта** (`ЧЧ:ММ:СС`)
3. **Время стопа** (`ЧЧ:ММ:СС`)
4. **Время простоя** (в формате ч.м.с: `ЧЧ:ММ:СС`)
5. **Элемент** (наименование агрегата или зоны)
6. **Примечание** (комментарий или инцидент)
7. **Элемент Примечание** (`[Элемент] [Примечание]`)
8. **Должность** (должность, ФИО или смена оператора)

* Все лишние служебные поля (*Событие*, *№ Зоны*, *№ Визита*, *Всего визитов*) по умолчанию отключены, но могут быть включены пользователем при необходимости.
* Время простоя всегда нормализуется в формат трех компонентов: **часы : минуты : секунды** (`ЧЧ:ММ:СС`).

### 3. Зеленый акцент заметок в Конструкторе
* Кнопка **`+ Заметка`**, бейджи режима заметок и новые элементы в Конструкторе переведены на изумрудный цвет (`#10b981`) для наглядного визуального разделения таймеров и заметок.

### 4. Время Старта и Финиша в заметках с авто-финишем
* Возможность вручную задать интервал события при создании заметки.
* Если конечное время не введено вручную, система автоматически подставляет в журнал актуальное текущее время добавления записи.

### 5. Индикатор состояния сетевого диска на дашборде
* Живой светодиодный индикатор статуса соединения с таблицей диска `P:\...` прямо в верхней информационной панели.

### 6. Честный расчет общего времени активности смены
* Счетчик времени активен только при работе хотя бы одного элемента, исключая ложное сложение времени параллельно запущенных таймеров.
