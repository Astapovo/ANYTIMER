# AnyTimer ⏱️

Необходимо контролировать время множества объектов для разных пространств одновременно, отправлять результаты в виде структурированной таблицы или создавать множество заметок с различными именами удобным способом с одного экрана? А может, и то, и другое? 

**ANYTIMER** разработан для решения данных задач: приятный интерфейс, быстрая установка PWA-приложением и полноценная работа без интернета. Инструмент создан для инженеров, производственных цехов, полевых условий и оперативного управления на ходу.

<a id="key-features"></a>
## 🌟 Ключевые возможности

* **Параллельный мульти-хронометраж без ограничений:** Одновременный независимый контроль десятков технологических процессов, линий, агрегатов или регламентных операций на едином визуальном экране.
* **100% Автономность и безопасность данных:** Приложение работает полностью локально в браузере пользователя (PWA Offline). Данные хронометража не передаются на сторонние облачные серверы и сохраняются даже при полной изоляции от интернета.
* **Прямая интеграция с инфраструктурой предприятия без бэкенда:** Автоматическая потоковая запись журнала событий в общие сетевые папки компании (например, `P:\...`) без промежуточных серверов, сложных баз данных или сторонних утилит.
* **Оперативное ведение журнала смен и инцидентов:** Мгновенная фиксация внештатных остановок, замен оборудования, заметок голосом или с клавиатуры с привязкой к конкретному оператору и агрегату.
* **Промышленная совместимость отчетов:** Данные автоматически формируются в стандарте, оптимизированном для прямого открытия в Microsoft Excel, интеграции с 1С, BI-аналитикой и системами диспетчеризации (SCADA).
* **Мгновенный старт без установки:** Запускается по прямой ссылке, работает на ПК, планшетах и смартфонах без необходимости установки дополнительного софта или получения прав администратора.

<a id="functions-desc"></a>
## ⚙️ Описание функций

<a id="constructor-types"></a>
### 1. Конструктор дашборда и типы элементов
* **Одиночный таймер (Single):** Независимый секундомер прямого отсчета или таймер с установкой целевого лимита времени (авто-стоп, звуковые и вибросигналы превышения).
* **Групповой таймер (Multi):** Контроль нескольких связанных компонентов внутри одной зоны с общим учетом совокупного времени работы.
* **Интерактивная карточка «Заметка»:**
  * Компактный элемент сетки с изумрудным акцентным оформлением (`#10b981`), идентичный по габаритам одиночному таймеру.
  * **Одиночный клик / тап:** Мгновенно открывает модальное окно для быстрого ввода комментария с клавиатуры.
  * **Долгое удержание (≥ 0.45 сек):** Сразу активирует окно в режиме диктовки и запускает запись речи через микрофон.

<a id="notes-time"></a>
### 2. Заметки и ручное управление временем
* **Голосовой ввод:** Встроенная система распознавания речи (Web Speech API) для фиксации событий без отрыва от производственного процесса.
* **Интервалы событий (Старт / Финиш):** Возможность задать точное время начала и окончания инцидента с автоматическим расчетом продолжительности в формате **ч.м.с** (`ЧЧ:ММ:СС`).
* **Авто-финиш:** Если конечное время не указано вручную, система автоматически подставляет в журнал актуальное текущее время добавления записи.

<a id="journal-analytics"></a>
### 3. Журнал событий и сквозная аналитика
* **Индикатор должности и смены:** Фиксация должности, ФИО или смены ответственного сотрудника в шапке журнала и в каждой сформированной строке.
* **Сквозной столбец «Элемент Примечание»:** Объединенное поле формата `[Элемент] [Примечание]` во встроенной таблице, CSV-выгрузках и сетевых файлах для мгновенной фильтрации и сводных отчетов в Excel.
* **Честный учет времени смены:** Счетчик общего времени панели ведет строгий астрономический хронометраж активности системы (активен, пока включен хотя бы один таймер, исключая ложное сложение времени параллельных процессов).

<a id="network-disk-sync"></a>
### 4. Синхронизация с сетевым диском (диск P:\)
* **Сетевая таблица Excel (File System Access API):** Потоковая дозапись строк в файл таблицы на сетевом диске (диск `P:\...`, корпоративная общая папка) в режиме реального времени.
* **Очередь буферизации (`fsQueue`):** Надежная защита от потери данных — при временной блокировке файла в Excel другими пользователями события накапливаются в памяти и автоматически дозаписываются при освобождении файла.
* **Индикатор статуса диска на дашборде:** Постоянный визуальный контроль связи (`Диск P: Вкл`, `Доступ`, `Ошибка`, `Выкл`) в строке сводки с быстрым переходом к настройкам в один клик.
* **Формат для Microsoft Excel:** Разделитель «точка с запятой» (`;`) и кодировка UTF-8 BOM (`\uFEFF`) для открытия файла в Excel двойным кликом сразу с корректной кириллицей и правильной разбивкой по столбцам.

<a id="data-output-config"></a>
### 5. Настройка вывода данных и структуры столбцов
* **Специализированное модальное окно «Настройка колонок вывода»:**
  * Доступно в один клик из окна сетевого диска (кнопка `[ ⚙️ Настроить столбцы таблицы (CSV / Excel) ]`), из Журнала (кнопка `[ ⚙️ Столбцы ]`), из главного меню «Настройки» и из окна «Заметка».
* **Строгий промышленный стандарт колонок по умолчанию («Лишние не нужно»):**
  1. `Дата` (формат `ДД.ММ.ГГГГ`)
  2. `Время старта` (`ЧЧ:ММ:СС`)
  3. `Время стопа` (`ЧЧ:ММ:СС`)
  4. `Время простоя` (в формате ч.м.с: `ЧЧ:ММ:СС`)
  5. `Элемент` (наименование агрегата или зоны)
  6. `Примечание` (текст заметки или причины простоя)
  7. `Элемент Примечание` (`[Элемент] [Примечание]`)
  8. `Должность` (должность, оператор или смена)
* **Интерактивное управление:**
  * Включение и отключение любых столбцов чекбоксами (включая служебные поля: *Событие*, *№ Зоны*, *№ Визита*, *Всего визитов*).
  * Перемещение порядка колонок стрелками **▲ / ▼**.
  * Кнопка **«По умолчанию (v8.01)»** для мгновенного сброса структуры к заводскому стандарту.
  * Все настройки сохраняются в памяти устройства и применяются синхронно: к Журналу на экране, ручному экспорту CSV и автозаписи на сетевой диск `P:\`.

<a id="integrations-presets"></a>
### 6. Интеграции и автоматизация
* **Webhook:** Отправка JSON-уведомлений о событиях старта, остановки и создания заметок в сторонние системы (Home Assistant, Node-RED, корпоративные чат-боты).
* **Пресеты и шаблоны:** Экспорт и импорт разметки дашборда в формате `.json` для быстрого переключения между технологическими линиями, цехами и сменами. **[Пресет для асу магнит 🗒️] (https://github.com/Astapovo/ANYTIMER/blob/main/MAGNIT%20ASU.json)**

<a id="ui-design"></a>
### 7. Эргономика и дизайн
* **Симметричный интерфейс (Glassmorphism):** Нижняя панель управления зеркально отражает верхнюю информационную шапку со скруглением углов к центру экрана.
* **4 профессиональные темы:** Кибер (Cyber Dark), Янтарь (Amber CRT / SCADA), OLED (True Black), Светлая (Stealth Light).
* **Screen Wake Lock:** Защита от автоблокировки и засыпания экрана при длительном непрерывном мониторинге процессов.

<a id="whats-new"></a>
## 📋 Что нового в v8.01

1. **Интерактивная настройка вывода данных (столбцов):** Окно выбора и изменения порядка колонок для Журнала, CSV/Excel и сетевого диска.
2. **Кнопка быстрой настройки в окне сетевого диска:** В окно «Сетевая таблица Excel (диск P:\)» добавлена прямая кнопка `[ ⚙️ Настроить столбцы таблицы (CSV / Excel) ]` со статусом активных полей.
3. **Строгий стандарт экспорта без лишних столбцов:** Базовая выгрузка оптимизирована под 8 обязательных полей: `Дата`, `Время старта`, `Время стопа`, `Время простоя` (в ч.м.с `ЧЧ:ММ:СС`), `Элемент`, `Примечание`, `Элемент Примечание`, `Должность`.
4. **Зеленое акцентное оформление заметок в Конструкторе:** Кнопка `+ Заметка`, бейджи режимов и новые элементы окрашены в изумрудный цвет (`#10b981`).
5. **Время старта и финиша в заметках:** Ручная установка интервала события с авто-подстановкой актуального времени финиша и расчетом длительности.
6. **Сквозной столбец «Элемент Примечание»:** Автоматическое объединение названия зоны и комментария через пробел во всех отчетах.
7. **Индикатор сетевого диска на главном экране:** Статус подключения к таблице диска `P:\...` вынесен в верхнюю строку сводки с переходом к настройкам в один клик.
8. **Честный расчет общего времени смены:** Счетчик общего времени не удваивает время при параллельной работе нескольких таймеров.
9. **Потоковая автозапись на сетевые диски:** Прямая потоковая интеграция с диском `P:\...` через File System Access API с буферной очередью `fsQueue`.
10. **Актуализация встроенной справки:** Интерактивное руководство пользователя во встроенном модальном окне обновлено под версию v8.01.

<a id="tech-stack"></a>
## 🛠️ Стек технологий

* **Frontend:** Vanilla JavaScript (ES6+), HTML5, CSS3 (Glassmorphism, CSS Custom Properties, Responsive CSS Grid & Flexbox).
* **Web APIs:**
  * **File System Access API:** Прямая работа с файлами и сетевыми дисками без сервера.
  * **IndexedDB API:** Долговременное хранение дескрипторов файлов и истории.
  * **Service Worker API & Cache Storage:** Полная автономная работа PWA Offline (кэш `anytimer-v8.01`).
  * **Web Speech API:** Распознавание голосовых заметок через микрофон.
  * **Web Audio API:** Генерация чистых звуковых частотных сигналов.
  * **Screen Wake Lock API:** Удержание экрана от выключения.
  * **Vibration API:** Тактильный отклик при управлении таймерами.
* **Шрифты и Иконки:** JetBrains Mono, Lucide Icons.
