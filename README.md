# AnyTimer ⏱️ v7.14

**[🚀 Запустить онлайн (GitHub Pages)](https://astapovo.github.io/ANYTIMER/)**

Автономный, независимый от интернета PWA-хронометр для строгого параллельного контроля времени, процессов, оборудования и зон. Работает полностью локально на вашем устройстве без бэкенда и регистрации. Создан для инженеров, производственных цехов, полевых условий и оперативного управления на ходу.

---

## 🌟 Ключевые возможности

### 1. 📱 100% Офлайн и PWA-приложение
* **Полная автономность:** Приложение устанавливается на рабочий стол смартфона (Android, iOS) или ПК (Windows, macOS, Linux) как нативная программа.
* **Работа без связи:** Кэширование всех ресурсов через Service Worker (`v7.14`).
* **Блокировка засыпания экрана (Screen Wake Lock):** Экран не гаснет, пока идёт отсчёт хотя бы одного таймера.

### 2. 🎨 Полный редизайн интерфейса и модальных окон (Новое в v7.14)
* **Легкий современный интерфейс:** Убраны громоздкие тени и утяжеляющие рамки. Все модальные окна, кнопки и карточки настроек облегчены и уменьшены для быстрой работы на любых экранах.
* **Компактные чипы привязки заметок:** В окне «Заметка в журнал» выводятся только номера панелей (`[★]`, `[№1]`, `[№2]`...), а полное имя выбранной панели отображается в шапке.
* **Редизайн кнопки «Добавить» на групповых панелях:** Аккуратная легкая кнопка-бейдж гармонично сочетается с карточкой зоны.
* **Киберпанк HUD-уведомления без рамок:** Сообщения раскрываются из центра с легким глитч-эффектом префикса и плавно сворачиваются при скрытии.
* **Интуитивный менеджер шаблонов (Пресетов):** Четкое разделение файловых операций — «Выгрузить файл» (экспорт JSON) и «Загрузить файл» (импорт JSON).

### 3. 📊 Оптимизированный CSV-экспорт для Excel
* **Четкая структура колонок:**
  * **Колонка 1 (Событие / Панель):** Выводится имя и номер панели (например, `№1 Станок 1` или `Общая`).
  * **Колонка 2 (Текст заметки / №):** Текст заметки выводится в колонку B, где для событий отображается номер запуска (`№`).
  * **Колонки 3-5 (Старт, Финиш, Длительность):** Время фиксации заметки попадает в колонку старта, а колонки финиша и длительности остаются пустыми (`-`), исключая дублирование текста в блок времени.
* **Сводка по панелям:** В конце CSV-файла формируется наглядная таблица общего времени и количества визитов по каждой панели.

### 4. 🔢 Нумерация панелей и жест долгого нажатия
* **Нумерация на основном экране:** Каждой созданной панели присваивается номер (`№1`, `№2`, `№3`...), визуально выделенный компактным моноширинным бейджем.
* **Жест удержания панели (Long-Press ≥ 450 мс):** При долгом нажатии на карточку панели открывается окно записи заметок с **автоматически выбранным номером этой панели**.
* **Тактильный Haptic-отклик:** Срабатывание подтверждается вибрацией устройства.

### 5. 🔮 Плавающая кнопка быстрых действий (Bubble FAB)
* **Удержание (Long-press ≥ 500 мс):** Мгновенно запускает голосовой набор заметки (Web Speech API).
* **Автоматическое приглушение музыки:** Во время голосовой диктовки фоновая музыка автоматически ставится на паузу и возобновляется после сохранения.
* **Кратковременный клик:** Меню быстрых действий (Конструктор, Заметки, Undo/Redo).
* **Перетаскивание (Drag & Drop):** В режиме конструктора кнопку можно свободно перемещать по экрану.

### 6. ⏱️ Два режима хронометража: Одиночный и Групповой
* **Одиночные таймеры:** Классический тумблер (Старт / Стоп) с поддержкой ширины 1x / 2x.
* **Групповые таймеры:** Учет потока объектов (№1, №2...) в одной зоне с индивидуальным «Стоп».

### 7. ⏳ Секундомер и Лимит обратного отсчёта
* **Секундомер:** Прямой отсчет времени от 00:00 вперёд.
* **Таймер с лимитом:** Установка дедлайна в формате **ЧЧ : ММ : СС** с сигналом (звук+вибро) или авто-стопом.

### 8. 📖 Актуализированное интерактивное руководство
* Справка в меню настроек со структурированными вкладками без лишних внешних упоминаний: Старт, Бабл & Жесты, Режимы, Журнал, Пресеты & Webhook, Офлайн PWA.

### 9. 🌐 Автоматизация и Webhooks
Отправка событий POST JSON на указанный URL в реальном времени:
```json
{
  "event": "start | stop | arrive | depart | note",
  "zoneId": 0,
  "zoneName": "Станок №1",
  "panelNum": 1,
  "localNum": 1,
  "durationMs": 84000,
  "text": "Текст заметки",
  "timestamp": "2026-09-01T12:00:00.000Z"
}
```

* **Шрифты & Иконки:** [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono), [Lucide Icons](https://lucide.dev/).
* **Web API:** Service Worker API, Cache Storage API, Web Speech API, Web Audio API, Vibration API, Screen Wake Lock API, Web Share API.
