# AnyTimer ⏱️ v8.02

Необходимо контролировать время множества объектов для разных пространств одновременно, отправлять результаты в виде структурированной таблицы или создавать множество заметок с различными именами удобным способом с одного экрана? А может, и то, и другое? 

**ANYTIMER** разработан для решения данных задач: приятный интерфейс, быстрая установка PWA-приложением и полноценная работа без интернета. Инструмент создан для инженеров, производственных цехов, полевых условий и оперативного управления на ходу.

<a id="key-features"></a>
## 🌟 Ключевые возможности

* **Параллельный мульти-хронометраж без ограничений:** Одновременный независимый контроль десятков технологических процессов, линий, агрегатов или регламентных операций на едином визуальном экране.
* **100% Автономность и безопасность данных:** Приложение работает полностью локально в браузере пользователя (PWA Offline). Данные хронометража не передаются на сторонние облачные серверы и сохраняются даже при полной изоляции от интернета.
* **Прямая интеграция с инфраструктурой предприятия без бэкенда:** Автоматическая потоковая запись журнала событий в стороннюю таблицу или общие сетевые папки компании (диск `P:\...`) без промежуточных серверов, сложных баз данных или сторонних утилит.
* **Полноценное ведение и редактирование журнала смен:** Возможность просматривать, вручную добавлять, корректировать (карандаш ✏️) и удалять (корзина 🗑️) любые записи остановок или заметок прямо в таблице.
* **Идеальная адаптивность для мобильных телефонов:** Таблица журнала на смартфонах оптимизирована: широкие зафиксированные столбцы, плавный горизонтальный свайп, исключено сплющивание текста в одну вертикальную строку.
* **Тактильный дизайн карточек «Заметки» с анимацией:** Стеклянный градиент, неоновое изумрудное дыхание, анимация наклона пера и световая вспышка при сохранении.
* **Промышленная совместимость отчетов:** Данные автоматически формируются в стандарте CSV (разделитель «;», UTF-8 BOM), оптимизированном для прямого открытия в Microsoft Excel без искажения кодировки.
* **Мгновенный старт без установки:** Запускается по прямой ссылке, работает на ПК, планшетах и смартфонах без необходимости установки дополнительного софта или получения прав администратора.

<a id="functions-desc"></a>
## ⚙️ Описание функций

<a id="constructor-types"></a>
### 1. Конструктор дашборда и типы элементов
* **Одиночный таймер (Single):** Независимый секундомер прямого отсчета или таймер с установкой целевого лимита времени (авто-стоп, звуковые и вибросигналы превышения).
* **Групповой таймер (Multi):** Контроль нескольких связанных компонентов внутри одной зоны с общим учетом совокупного времени работы.
* **Интерактивная карточка «Заметка»:**
  * Компактный или широкий элемент сетки с изумрудным оформлением.
  * **Одиночный клик / тап:** Мгновенно открывает модальное окно для быстрого ввода комментария с клавиатуры.
  * **Долгое удержание (≥ 0.45 сек):** Сразу активирует окно в режиме диктовки и запускает запись речи через микрофон.

<a id="notes-design"></a>
### 2. Карточки «Заметка» с премиальной анимацией
* **Глубокий тактильный дизайн:** Многослойный полупрозрачный градиент с изумрудным свечением (`#10b981`), неоновыми гранями и мягким дыханием в режиме ожидания (`noteAmbientBreathing`).
* **Интерактивная анимация пера:** При наведении или взаимодействии перо в бейдже карточки выполняет покачивание (`notePenWiggle`).
* **Световая вспышка фиксации:** При успешном добавлении или изменении заметки карточка подтверждает действие плавной изумрудной волной свечения (`noteSaveFlash`).
* **Умный информационный пузырь:** Внутри карточки отображается счетчик записей, время последней фиксации и превью текста последнего комментария с моноширинной типографикой.
* **Голосовой ввод и тайминги:** Поддержка распознавания речи (Web Speech API) и ручного задания времени начала и окончания события с расчетом времени в формате `ЧЧ:ММ:СС`.

<a id="journal-analytics"></a>
### 3. Журнал событий, адаптивная таблица и редактирование
* **Исправление для мобильных телефонов:** Таблица журнала больше не сплющивается в вертикальные полоски на экранах смартфонов. Установлена адаптивная минимальная ширина (`min-width: 860px`), `white-space: nowrap` для служебных полей, адаптивный перенос текста примечаний и подсказка о горизонтальном свайпе.
* **Полноценное редактирование любых записей:** Каждая строка таблицы оснащена кнопками быстрого редактирования ✏️ и удаления 🗑️. Можно скорректировать агрегат, время старта/стопа, простой (ч:м:с), примечание и должность оператора как для заметок, так и для таймеров.
* **Ручное добавление записей:** Кнопка **«➕ Запись вручную»** позволяет внести событие в журнал смены задним числом без запуска секундомера.
* **Сводная статистика смены:** Отображение общего числа записей и точного суммарного времени простоя оборудования в шапке журнала.
* **Сквозной столбец «Элемент Примечание»:** Объединенное поле формата `[Элемент] [Примечание]` для мгновенной фильтрации и группировки в Excel.
* **Очистка журнала с подтверждением:** Возможность безопасно обнулить журнал перед началом новой смены.

<a id="unified-hub"></a>
### 4. Единый хаб: Сторонняя таблица (диск P:\) и правила выгрузки
* **Единый центр управления:** Все разрозненные настройки таблицы и журнала объединены в одном удобном окне **«Журнал и сторонняя таблица (диск P:\ / Excel)»**.
* **Быстрый доступ:** Хаб открывается в один клик из главного меню, из шапки Журнала (кнопка `[ ⚙️ Настройка таблицы ]`) и по клику на индикатор сетевого диска в строке сводки.
* **Статус подключения сторонней таблицы:** Отображение имени файла, полного пути на сетевом диске и статуса связи (`АКТИВЕН` / `ОФФЛАЙН`).
* **Правила добавления данных в стороннюю таблицу:**
  * ✅ **Остановки таймеров** — фиксация времени простоя, стопа и количества визитов.
  * ✅ **Заметки оператора** — отправка текстовых и голосовых комментариев инцидентов.
  * ⬜ **Запуски таймеров** — опциональная фиксация моментов пуска оборудования.
* **Очередь буферизации (`fsQueue`):** Защита от конфликтов доступа при открытом файле в Excel на других рабочих станциях.

<a id="data-output-config"></a>
### 5. Настройка структуры колонок вывода
* **Управление составом и порядком столбцов:** Включение и отключение полей чекбоксами, изменение порядка следования стрелками **▲ / ▼**.
* **Интуитивные и понятные описания полей:** Каждая колонка имеет четкое русскоязычное назначение.
* **Стандартный набор по умолчанию (v8.02):**
  1. `Дата` (`ДД.ММ.ГГГГ`)
  2. `Время старта` (`ЧЧ:ММ:СС`)
  3. `Время стопа` (`ЧЧ:ММ:СС`)
  4. `Время простоя` (`ЧЧ:ММ:СС`)
  5. `Элемент` (наименование оборудования)
  6. `Примечание` (текст инцидента/заметки)
  7. `Элемент Примечание` (`[Элемент] [Примечание]`)
  8. `Должность` (смена / оператор)
* Опциональные поля: `Событие`, `№ Зоны`, `№ Визита`, `Всего визитов`.
* Кнопка **«По умолчанию (v8.02)»** для мгновенного сброса.

<a id="integrations"></a>
### 6. Интеграции и автоматизация
* **File System Access API:** Прямая потоковая запись в файлы `.csv` на Windows / Edge / Chrome.
* **Webhook:** Отправка JSON-событий (старт, стоп, заметка) в Home Assistant, Node-RED и SCADA.
* **Экспорт и шеринг:** Кнопки «Скачать CSV» и «Поделиться» через Web Share API.

<a id="ergonomics"></a>
### 7. Эргономика и дизайн
* 4 темы оформления: Кибер (Dark), Светлая, Янтарь (Amber), OLED.
* Фоновое музыкальное сопровождение с автопаузой при диктовке.
* Блокировка засыпания экрана (Wake Lock API).

## 📋 Что нового в v8.02

1. **Единый хаб управления Журналом и сторонней таблицей:** Ликвидирована путаница разрозненных пунктов меню — настройки подключения к сетевому диску P:\, правила автозаписи событий и порядок колонок объединены в одно удобное окно.
2. **Полноценное редактирование записей Журнала:** Теперь можно отредактировать ✏️ или удалить 🗑️ любую строку журнала (как заметки, так и остановки таймеров), исправить агрегат, время старта/стопа или длительность простоя.
3. **Ручное добавление событий в Журнал:** Добавлена кнопка «➕ Запись вручную» для фиксации инцидентов задним числом.
4. **Исправление мобильной таблицы Журнала:** Устранено сжатие столбцов в одну вертикальную строку на экранах телефонов. Таблица получила минимальную ширину 860px, аккуратные непереносящиеся служебные поля, закрепленную шапку (`sticky header`) и закрепленную колонку действий.
5. **Премиальный редизайн карточек «Заметка»:** Элементы заметок оформлены в современном изумрудном стиле с неоновым дыханием, анимацией наклона пера при наведении и световой вспышкой при сохранении комментария.
6. **Обновление PWA кэша `anytimer-v8.02`:** Актуализированы манифест, Service Worker и локальные ресурсы.
