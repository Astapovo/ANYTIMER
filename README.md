# AnyTimer ⏱️ v7.18


**[🚀 Запустить онлайн (GitHub Pages)](https://astapovo.github.io/ANYTIMER/)**

Необходимо контролировать время множества объектов для разных пространств одновременно, отправлять результаты в виде структурированной таблицы или создавать множество заметок с различными именами удобным способом с одного экрана? А может, и то, и другое? 

**ANYTIMER** разработан для решения данных задач: приятный интерфейс, быстрая установка PWA-приложением и полноценная работа без интернета. Инструмент создан для инженеров, производственных цехов, полевых условий и оперативного управления на ходу.

---

## 🚀 Ключевые возможности

* **Параллельный контроль зон и объектов:** Единое рабочее пространство (Конструктор) для одиночных и групповых таймеров. Поддержка прямого отсчета и лимитов с авто-стопом или звуковым/вибро сигналом.
* **Голосовые и текстовые заметки (Кнопка «A»):** Удержание центральной кнопки мгновенно активирует микрофон для записи лога с привязкой к конкретному объекту. Фоновая музыка ставится на паузу автоматически.
* **Структурированный журнал и экспорт:** Все события (старты, стопы, комментарии) логируются. Выгрузка в CSV-файл с детализацией по событиям и итоговой сводкой отработанного времени по каждой зоне.
* **100% Автономность:** Работает локально на устройстве (Service Worker). Никаких серверов и регистраций. Поддерживает удержание экрана от засыпания (Wake Lock).
* **Интеграция с автоматизацией:** Настраиваемый Webhook для отправки POST-событий в формате JSON (старт, стоп, текст заметки) в сторонние системы (например, Home Assistant).
* **Шаблоны цехов (Пресеты):** Сохранение текущей конфигурации таймеров, экспорт и импорт разметки в `.json`.

## 🛠️ Стек технологий

* **Frontend:** Vanilla JavaScript (ES6+), HTML5, CSS3 (Glassmorphism).
* **Web API:** Service Worker API, Cache Storage API, Web Speech API, Web Audio API, Vibration API, Screen Wake Lock API.
* **Шрифты и Иконки:** JetBrains Mono, Lucide Icons.
